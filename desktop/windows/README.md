# 审迹工作台 · Windows x64 本机体验

给两位负责人核对六个业务入口。请使用虚构的测试资料，每个 Windows 用户有一份专用工作区。这个内测包不连接团队账号、权限和订阅服务。

## 打开方式

1. 把整个 ZIP 解压到新文件夹。
2. 双击 ShenyiWorkbench.exe，保留同目录的其他文件。
3. 可从左侧进入招投标及记录、项目汇总表、审计程序、报告出具、成本核算和资料库。立项沿用原业务界面的前置条件。

关闭再打开同一份体验版，可在原 Windows 用户下继续。测试资料保存在独立的 Shenyi-Workbench-LocalReview 应用数据目录中。团队客户端、浏览器中的旧资料和其他 Windows 用户的数据需分别管理。多人共用一个 Windows 账号会共用本体验区。

本包用于本地业务走查。公开发行还需完成身份与业务授权整合、可用的客户安装器、发布者签名，以及安装、升级、回滚、数据恢复和真实脱敏样本验收。网页内打开外部链接、新弹窗、内嵌文档预览及云账号功能在此原型受限。显示的旧版页面文字来自原业务源码。

## 开发人员构建

Windows 上在仓库根目录运行 `node desktop/windows/build.mjs <electron-v45.3.2-win32-x64.zip> <仓库外的新目录>`。脚本校验固定的官方归档，提取当前 Git HEAD 的 dist，再复制本目录的壳和说明。运行时的 LICENSE 和 LICENSES.chromium.html 随包保留。桌面代码和后续调试使用仓库指定的 Node 24.x 版本。
