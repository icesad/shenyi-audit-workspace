# 年续费与下一年度席位

本地服务端模拟候选承接用户确认的年度席位规则。本团队技术管理员可查询下一年度的默认席位数并在建单时调整。默认取原期限结束前一毫秒的已购容量总和。原期限已过也使用该历史时点，没有既有期限时默认零席。当前启用数和邀请预留数是占用事实，可用于提示和减席检查。[订阅与席位决策](SUBSCRIPTION_SEAT_DECISION.md)

在原有严格设备校验与团队管理能力开启的服务端，`GET /api/teams/:teamId/billing/renewal-seats` 返回默认席位、原期限版本和终点、当前已承诺席位及合成席位年单价。续费订单仍用 `POST /api/teams/:teamId/billing/orders`，可传 `selectedSeats`。省略时由服务端取默认。合成整单金额为团队年费加席位数量乘席位年单价。订单保存默认数量、选择数量、合成单价及当时期限。同请求编号的重复操作返回原单，不能借重试改变席位或重算金额。

网关确认金额后先保存收款记录，再按既有北京自然年规则兑现。未到期续费从原终点起算。到期后续费从首次可信收款确认时刻起算。选定席位由同一提交写入这个新增年期，提前付款期间本期数量不变。原收款事实与最终权益可分别核对，写入失败时保留验款记录，回滚本次新期限、容量和成功回执。同一支付事实重试只提交一次。

减席前须先释放足够的启用或邀请预留席位。建单和兑现时都检查当时的承诺数。付款后如承诺数增加至超过订单数量，保留已验收款，待释放席位后重试原订单。若下期已有重叠的可信容量记录，订单同样留待核对。候选保持同团队已确认订单的处理顺序，较早待处理的已付款订单需先核对。现有成员不会自动停用。

原有不含席位选择的年单保持原期限语义。合成席位报价在服务端显式配置，撤下目录后已保存订单仍可查询及核对。购买席位不产生审计资料权限。正式价格、平台支付、退款、桌面自助购买与生产上线另行验收。
