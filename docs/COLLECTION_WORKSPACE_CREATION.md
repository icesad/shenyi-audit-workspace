# 中标前的采集工作区

经理／合伙人可以先在本团队建立仅用于资料采集的工作区。界面明确标明“未正式立项”；创建不产生报价、业务编号、合同或正式来源。中标后的正式化属于后续独立工作，继续使用可信的最新中标报价与原编号规则。

## 正常操作

1. 登录并完成本机设备验证，从“项目采集与资料核对”选择本团队。项目列表为空也可以创建工作区。
2. 填写名称，逐项选择自己的初始采集查阅、管理、核对权限，输入当前密码并明确确认。三项默认不勾选；管理或核对须同时有查阅。
3. 只作为负责人创建时，请先阅读警示：本片不能事后给自己补采集权限。需要立即建任务及分派时，应明确选择查阅与管理；核对仍为独立选项。
4. 成功后会显示服务端生成的工作区标识、创建回执和重新查询的当前能力。拥有管理权时可新建采集任务，将其指派给本团队有效实习生／助理。
5. 员工只从本人任务入口上传原件；获项目查阅及核对权的经理／合伙人从项目核对入口查看。撤权、停用、换机和设备暂停继续遵循原规则。

## 查询与恢复

提交前显示公开的创建查询编号，请保留。真实提交后断网或回复丢失时显示结果未知；恢复设备会话后，只用原编号查询，不自动重发创建。

同一账号和团队关闭再打开面板，保留在途／未知编号及禁止重复提交的状态。重新登录后可手动输入本人保存的编号。查询404不证明在途请求永远不会完成，不能据此自动重复创建。

回执记录创建时名称和初始权限，当前能力以服务端重新查询的项目为准。密码、确认和上一账号内容在关闭或身份变化时清空；查询编号不含密码。

## 权限与数据边界

- 仅当前有效经理／合伙人可以创建，仍须本团队有效成员身份、密码复核和持钥设备会话。纯技术管理员、实习生、助理不能创建。
- 创建者只管理本工作区授权，职级不会扩大到其他团队或项目。采集工作区的资料清单模块始终锁定，即使误写材料授权也不能使用。
- 类型、创建来源和永久回执在服务端保存，不能由客户端传入创建人、项目ID、报价或类型来伪造。创建来源与旧正式项目迁入来源互斥。
- 既有登记项目保持原8字段兼容投影，新工作区另有明确类型字段。既有登记不证明客户资料已经迁入或正式审计完成。
