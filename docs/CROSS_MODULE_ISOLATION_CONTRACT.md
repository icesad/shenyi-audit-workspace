# M4 同项目四模块组合隔离合同

本项在`93d2708`后补组合回归与独立真实HTTP复核，不增加产品权限。最终提交、命令及分层结果见[进度](../进度.md)。

一份合成SQLite、同一工作区W及不同的旧来源Q，同时具有非空材料与历史原件、立项来源、账表快照、有效Office底稿及既有冻结。负责人明确准备数据，非负责人partner-a为主要被测者，不授采集权。不得以四个独立库或空表404代替组合验证。

验收包含无权限、四种单模块授权、四模块正向及逐模块撤read。材料仅read即可获取本人计划和保全包；来源及底稿导出各需read与export。材料依赖标志非法的400与数据出口404分列。收回一个模块时，其他模块原有授权及数据仍应保持。

正向正文及包也须符合本域公共投影，不能夹带兄弟私有值；404正文和头部须保持公共错误边界。共享W/Q、业务号、合同允许的最小项目发现不作私有canary。材料授权后刷新projectRevision，各域grantRevision独立，不能把过期409算作隔离通过。原件、版本、填写及既有freeze保持，合法grant和audit变化单独列证。

永久回归走真实严格application及SQLite；TCP另用独占端口和正常主客户端／内存Ed25519密钥，不替换fetch或Response。原始签名请求先完成，正常重新登录后仅用新会话。历史fixture时间与实时HTTP边界明示，不清限流；GET空正文可独立复算，POST仅复核摘要头时不得声称独立重算全文。

客户端先行拒绝不等于binary路由返回404，必须按实际wire分别报告。独立运行用新输出目录，服务先关闭再清数据库。本门不代替[未通过的OS门](NATIVE_OS_FILE_DIALOG_ACCEPTANCE.md)、Mac、DPAPI、TLS、发行、一键、共享库或生产验收；报告权限仍待原答复，Goal继续。
