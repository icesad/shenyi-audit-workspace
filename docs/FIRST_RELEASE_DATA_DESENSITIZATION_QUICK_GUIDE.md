# 审易 Excel 脱敏一页说明

**脱敏就是在本机做一份新表，把用不到的敏感信息删掉，要对得上的名称换成代号，验算用的数字按原样保留。**

**原表留在指定位置 → 新建 Excel 做副本 → 对数字、查遗漏 → 复核后才上传**

## 表里哪些要删、要换、要留？

| 怎么处理 | 举个例子 |
| --- | --- |
| **删掉用不到的** | 联系人、手机号、银行账号、无关备注，整列去掉。 |
| **换成代号** | 「演练甲公司」改成「公司01」，「演练乙供应商」改成「供应商01」。同一个项目里，同一家公司每次用同一个代号。需要按凭证对账时，同一张凭证的每一行也用同一个凭证代号。 |
| **留着验算** | 获准共享的日期、科目编码、每笔的行号、借方和贷方金额都照原样，负数和小数也保留。要和余额表、报表一起对，还要保留它们的期初、期末、本期发生额等所需金额及对应关系。 |

原件留在客户或事务所指定的位置。写有「真实名称对应哪个代号」的表单独加密保管。金额或日期没获准共享，就在获准的本地环境验算，只交获准的结果。

## 实习生试一次，用虚构数据

1. **做原表。** 在 Excel 输入下面两行，再给两行都填上公司名「演练甲公司」、供应商名「演练乙供应商」和联系人「演练小张」。

   | 凭证号 | 日期 | 行号 | 科目 | 借方（元） | 贷方（元） |
   | --- | --- | --- | --- | ---: | ---: |
   | 原凭证01 | 2026-01-15 | 1 | 应付账款 | 120 | 0 |
   | 原凭证01 | 2026-01-15 | 2 | 银行存款 | 0 | 120 |

2. **做新表。** 新建空白 Excel，只把要留的内容用「选择性粘贴 → 值」贴进去。两行的凭证号都改成「凭证01」，公司和供应商按上表换成代号。联系人列省掉。借贷金额照抄。
3. **保存后重开。** 两行都应属于「凭证01」。分别选中借方、贷方的两个金额，Excel 底部的「求和」都应是 **120 元**。搜索「演练」应无结果，检查底部有没有多余工作表。再把副本的借方 120 改成 121 试一次，这时借贷应差 **1 元**。把两次结果告诉米老师。

## 谁看过才能上传？

真实项目先确认客户同意共享哪些内容。**拟定分工**是米老师或指定同事复核账能不能对上，数据安全复核人检查表里还有没有不该发的内容，项目负责人批准后，由指定人员上传这一份副本。

首版在本机按规则处理。如果后续获准使用本地 AI，只让它提示哪里可能漏了，由人复核。

请米老师帮忙确认三件事。**哪些栏必须原样留着？对完合计后还要查什么？上传前请哪两位分别看账和查遗漏？**
