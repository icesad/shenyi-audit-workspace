## 可供属地咨询的业务说明

> 审易拟提供 Windows 和 macOS 审计团队协作客户端，并由中国内地服务端提供独立账号、电脑绑定、项目权限和资料采集。公开官网提供产品说明和帮助，计划提供下载。已开通团队由管理员邀请员工，提交的文件只在该团队和项目的授权范围内使用。计划销售本产品的团队年订阅和员工席位，自助付款入口待确认。审计专业判断、复核和报告签发由使用团队按自身职责处理。

- 请属地通信管理部门根据公开官网、受限团队服务及拟收费功能判断备案或许可路径，并说明 API 子域名及未来增加购买入口时是否需补充申报。记录答复渠道、日期及具体适用场景。 [互联网信息服务管理办法](https://sdca.miit.gov.cn/zwgk/fgbz/art/2026/art_fea940f81f1d423e87101adf147ab979.html)
- 真实资料试点前，核对各方的数据处理职责、存储地、保留和删除、退出后返还、访问范围和审计日志。手机号、设备绑定信息、审计材料分别登记。涉及委托处理或敏感个人信息时，按实际情况核对约定及个人信息保护影响评估等要求。 [个人信息保护法第二十一条、第五十五条](https://www.miit.gov.cn/zwgk/zcwj/flfg/art/2022/art_04a0f1fb5df244e39688fd5372623a8d.html)

| 时点 | 负责人可执行的动作 | 保留的回执 |

## 商户接入与正式上线

**收款决策。** 确认首发渠道、收款主体、价格和席位、发票及退款条款、官网或客户端入口。若选择官网 PC 扫码，可评估微信支付 Native。官方接入包括商户产品权限及符合要求且已认证的 AppID 绑定。另核对既有微信扫码登录的应用类型。 [微信支付 Native 产品介绍](https://pay.wechatpay.cn/doc/v3/merchant/4012791874) · [接入准备](https://pay.wechatpay.cn/doc/v3/merchant/4015614538)

**验收回执。** 商户授权后记录实际测试订单、可信收款通知、查单对账、权益到账和退款结果。双人合成走查按现有评审单，真实试点另记授权范围和结果。正式上线还需记录 Windows 与 macOS 签名安装验收、实际访问地址、运行版本及回滚负责人。 [双人评审单](PILOT_OWNER_REVIEW.md)
