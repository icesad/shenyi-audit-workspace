# 审易国内上线申请准备

产品负责人已确认由上海注册的企业运营官网和团队服务，由同一企业收取年费。现有记录显示暂无域名和阿里云资源。此单用于负责人核对和后续咨询。公开网站、团队服务和收款分别按实际回执验收。官方资料于 2026-11-19 核对。

| 先确认 | 确认后可推进 |
| --- | --- |
| 企业全称、营业执照经营范围及既有备案 | 核对主体资料，判断首次备案、新增互联网信息服务或接入备案。 |
| 网站负责人、商户管理人员、结算及开票安排 | 明确企业代表、授权分工和对公账户，核对年费与席位合同和发票。 |
| 云资源预算和试点规模 | 按团队数、并发、附件、保留量估算实例、磁盘、备份和流量。 |
| 首版对外范围 | 确认官网是否开放注册、下载和自助购买，以及哪些真实资料获准进入试点。 |

正式申请所需的证照、负责人核验、结算账户和密钥由经授权人员在各官方平台提交或配置。

## 可供属地咨询的业务说明

> 审易拟由上海注册企业运营，团队年费由该企业收取。拟提供 Windows 和 macOS 审计团队协作客户端，并由中国内地服务端提供独立账号、电脑绑定、项目权限和资料采集。公开官网提供产品说明和帮助，计划提供下载。已开通团队由管理员邀请员工，提交的文件只在该团队和项目的授权范围内使用。计划销售本产品的团队年订阅和员工席位，自助付款入口待确认。审计专业判断、复核和报告签发由使用团队按自身职责处理。

- 请属地通信管理部门根据公开官网、受限团队服务及拟收费功能判断备案或许可路径，并说明 API 子域名及未来增加购买入口时是否需补充申报。记录答复渠道、日期及具体适用场景。 [互联网信息服务管理办法](https://sdca.miit.gov.cn/zwgk/fgbz/art/2026/art_fea940f81f1d423e87101adf147ab979.html)
- 真实资料试点前，核对各方的数据处理职责、存储地、保留和删除、退出后返还、访问范围和审计日志。手机号、设备绑定信息、审计材料分别登记。涉及委托处理或敏感个人信息时，按实际情况核对约定及个人信息保护影响评估等要求。 [个人信息保护法第二十一条、第五十五条](https://www.miit.gov.cn/zwgk/zcwj/flfg/art/2022/art_04a0f1fb5df244e39688fd5372623a8d.html)

## 上海企业的申报入口

- 上海市通信管理局公告说明，备案材料可由对应接入服务商或适用的应用分发平台提交。如需申请增值电信业务经营许可，按实际业务和地域范围在工信部政务服务平台选择事项。官网展示与下载、受限团队 API、资料存储、订阅收费和拟增加的购买入口，应一并写入咨询说明，取得适用路径后再提交。 [上海管局公告](https://shca.miit.gov.cn/zwgk/zcwj/wjfb/art/2024/art_d4f09cb8e7004ac19c2af7f6fd8fb32a.html) · [工信部许可事项](https://ythzxfw.miit.gov.cn/bssx/alx/dxhhlw/art/2025/art_5898effe0ba947d0bbfeff111b09f7fe.html)
- 按阿里云上海企业备案指引，准备营业执照和主体、网站负责人核验材料，主体负责人填写法定代表人。网站负责人另有其人时，按要求准备上海模板授权书。采购前核对当期域名核验、有效期和中国内地云资源的备案资格。 [上海备案规则](https://help.aliyun.com/zh/icp-filing/icp-filing-regulations-for-shanghai) · [备案前期准备](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/overview/)

## 域名、阿里云与备案顺序

| 时点 | 负责人可执行的动作 | 保留的回执 |
| --- | --- | --- |
| 主体和品牌确定后 | 准备域名候选。部署方案可将官网和团队 API 配置为两个 HTTPS 入口。核对域名后缀、注册服务机构及持有人是否满足备案要求，按确认的主体、价格与年限注册并实名。 | 域名归属、实名认证状态、到期日。 [阿里云域名和服务器备案条件](https://help.aliyun.com/zh/icp-filing/basic-icp-service/support/for-the-record-process-faq) |
| 采购服务器前 | 在阿里云备案控制台核对拟购中国内地产品、公网接入条件、计费方式和购买时长。确认哪个账号购买资源、哪个账号提交备案，若不同账号再核对备案服务码适用性。 | 产品、地域、预算、备案资源资格、资源负责人。 [阿里云备案服务器检查](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/icp-filing-server-access-information-check) |
| 域名实名、接入资格和属地路径确认后 | 准备主体与负责人资料、服务名称和描述、域名及接入信息。已有主体记录时先核对是否适用新增网站或接入备案。属地材料以申请界面为准。 | 阿里云初审、工信部核验、管局结果、备案号及展示核对。 [阿里云备案流程](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/icp-filing-application-overview) |
| 准备公开访问时 | 在获准的测试或部署环境验证两端 HTTPS、实例身份、设备登录和备份恢复，再从实际办公网络验证。公开域名和服务按属地要求启用。 | 构件版本、自检、办公访问和恢复回执。 [Linux 部署与自检](LINUX_TEAM_DEPLOYMENT.md#一次性上线检查) |
| 网站开通后 | 登记实际开通日，按适用要求办理公安联网备案、维护网站标识。等保按系统定级及属地要求跟踪。 | 开通日、办理编号及后续维护事项。 [国内上线时点](COMMERCIALIZATION_ROADMAP.md#4-国内上线手续与时点) |

## 商户接入与正式上线

**收款准备。** 确认首发渠道、价格和席位、发票及退款条款、官网或客户端入口。若选择官网 PC 扫码，可评估微信支付 Native。企业按渠道准备营业执照、法定代表人核验材料和对公银行账户，完成账户验证、审核和签约。Native 另需适用的已认证 AppID、产品权限和商户绑定。微信扫码登录的应用审核另行核对。 [微信支付企业材料](https://pay.wechatpay.cn/static/applyment_guide/applyment_detail_website.shtml) · [Native 接入准备](https://pay.wechatpay.cn/doc/v3/merchant/4015614538)

**验收回执。** 商户授权后记录实际测试订单、可信收款通知、查单对账、权益到账和退款结果。双人合成走查按现有评审单，真实试点另记授权范围和结果。正式上线还需记录 Windows 与 macOS 签名安装验收、实际访问地址、运行版本及回滚负责人。 [双人评审单](PILOT_OWNER_REVIEW.md)
