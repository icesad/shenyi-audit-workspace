# 账表校验：首版只读范围与来源决定

日期：2026-11-17。

用户已选择“先只开放查阅，运行校验以后再定”。本轮按提问中的分工，由项目负责人验证当前密码，为自己或本项目有效经理／合伙人单独授予查阅权；不从职级、负责人、技术管理员、材料或立项来源权推导。

用户随后明确来源方式：**从旧版显式导出快照，由项目负责人核验并验证密码后导入团队；只供查阅，不运行校验、不写底稿。** 普通查阅成员不因查阅权获得来源导入权。

旧版已有手动映射校验记录保存在 `ProjectWorkspaceStore` 的 `reconciliation` 中，包括原输入、列映射、来源引用、结果、两个哈希和计算时间。团队资料保全包没有携带这份工作区记录。旧版自动账表校验会在进入页面时运行且结果不在该字段保存，因此不能把旧页面直接嵌入团队版只读入口。

首版团队入口只显示已导入记录及来源说明。没有记录时如实显示空状态，不生成“0项差异”或自动计算结果。查阅不运行任一校验引擎，不修改映射、确认、资料核对、工作区答案、冻结或原件；不生成待复核填写建议，不导出审计报告或形成审计意见。

来源文件和内部哈希只能说明数据格式、输入及列映射的绑定一致，不能证明现实账套完整、原件真实、结果最新或计算正确。负责人确认记录为其来源核验，不等于软件已重新计算或审计签发。将来运行校验、底稿写入、导出或其他专业动作须另行确认。

实施范围与尚未完成项见[只读快照合同](LEDGER_CHECK_SNAPSHOT_CONTRACT.md)。最高审核账号恢复仍按[首版延期决定](PRIVILEGED_ACCOUNT_RECOVERY_DECISION.md)，与本项无关。
