# 审易本地 Excel 脱敏试跑教程

**给实习生的合成演练 · 2026-11-22**

用下方虚构数据，在 Excel 桌面版离线做一次“删列、换代号、保留验算值”。在本机完成后，将第 5 节的结果交给米老师。客户资料、原件、映射表和实际上传请按项目审批办理。首版规则工具和 AI 查漏能力仍待双方确认，本练习用 Excel 公式演示可重复执行的本地规则。 [首版脱敏方案及字段表](FIRST_RELEASE_DATA_DESENSITIZATION.md)

## 1. 准备工作簿和样例

1. 在合成测试目录新建 `脱敏工作副本.xlsx`，建 `原序时账`、`映射` 两个工作表。先在 `原序时账` 把 A 至 D 列设为“文本”，E、F 列设为数值。代码 `01002` 的第一位是零，日期采用 ISO 文本。
2. 把下方“原序时账”数据粘到 `原序时账!A1`。把“凭证映射”粘到 `映射!A1`，把“客商映射”粘到 `映射!D1`。如果粘贴后全在一列，选中该列，在“数据 → 分列”选择“分隔符号 → 制表符”，并在导入预览把 A 至 D 列设为“文本”。
3. 记录本次范围。项目 `DEMO-P01`，主体 `DEMO-E01`，期间 `2026-01-01` 至 `2026-01-31`，币种 `CNY`，单位元，金额精度 2 位。

## 2. 执行规则并生成值版

1. 在 `原序时账!K1` 写 `凭证代号`，`L1` 写 `客商代号`。在 K2、L2 分别输入下面两条公式，再把 `K2:L2` 填充到第 7 行。全部 6 行都应匹配。将查找设为完全匹配，确认映射表每个源键仅有一条。 [Microsoft VLOOKUP](https://support.microsoft.com/zh-cn/excel/functions/vlookup-function)

```excel
=IFERROR(VLOOKUP(B2,映射!$A$2:$B$4,2,FALSE),"未匹配")
=IFERROR(VLOOKUP(G2,映射!$D$2:$E$3,2,FALSE),"未匹配")
```

2. 新建空白 `DEMO-P01_脱敏三表_v01.xlsx`，只保留 `序时账`、`科目余额表`、`资产负债表` 三张可见表。先把新 `序时账` 的 A 至 D 列及新 `科目余额表` 的 A 列设为“文本”。新序时账按下表顺序，从工作副本的指定列分别用“选择性粘贴 → 值”写入，保留原行顺序。 [Microsoft 粘贴选项](https://support.microsoft.com/zh-cn/excel/paste-options)

| 输出地址 | 使用原序时账的列 | 输出字段 |
| --- | --- | --- |
| A | A | 末级科目编码 |
| B | K | 凭证代号 |
| C 至 F | C 至 F | 分录行号、日期、借方发生额、贷方发生额 |
| G | L | 客商代号，本练习用于验证代号一致 |

最终序时账只含这 7 列。原 B、G 使用代号替换，H 至 J 的联系人、账号和内部摘要留在工作副本，映射表也保存在本地工作副本。红冲的两条 `-20` 分别保留在原借方和贷方列。

3. 将下方两张表以值分别粘到新文件对应工作表的 A1，用于交叉核对。保存并重开新文件。工作表应只有获准字段，合成科目 `01002` 重开后仍是 5 位文本。用“查找”按工作簿搜索 `SRC-`、`合成联系人`、`DEMO-BANK`、`演练内部备注` 和原客商名。任何命中都要退回核对。最后核对隐藏表、行列、批注、作者属性、公式、外链和缓存。支持该功能的 Excel 桌面版可以运行“文件 → 信息 → 检查问题 → 检查文档”。 [Microsoft 工作簿隐藏数据检查](https://support.microsoft.com/zh-cn/office/collab-files/remove-hidden-data-and-personal-information-by-inspecting-documents-presentations-or-workbooks)

## 3. 验算并记下数字

在工作副本或另一个本地核对表做计算，保持最终值版文件只含上面的三张表。

| 项目 | 通过标准 |
| --- | --- |
| 行数和凭证范围 | 6 条分录，3 张凭证，每张凭证两行，并保留原日期。`PZ-01` 和 `PZ-02` 对应同一客商 `S-01`，`PZ-03` 对应 `S-02`。 |
| 序时账借贷 | `SUM(E2:E7)` 和 `SUM(F2:F7)` 各为 `150`。`PZ-02` 红冲金额仍为 `-20`，原方向保持。 |
| 科目余额表 | 期初借贷各 `1000`，本期发生借贷各 `150`，期末借贷各 `950`。逐科目按“期初借 − 期初贷 + 本期借 − 本期贷”与期末净额核对。 |
| 报表勾稽 | 期初 `1000＝200＋800`，期末 `950＝100＋850`。从借减贷净额映射到报表时，银行科目 `01002` 取 `+1`，应付 `02202` 和资本 `04001` 各取 `-1`。 |
| 本机抽查回溯 | 只在工作副本按代号分别找回 `PZ-01`、`PZ-02`、`PZ-03` 的 2 行，核对期初日、红冲和期末日，记录实际查到的源行。 |

可选的审易本机复跑从独立合成项目开始。先把值版工作簿附到本机项目的资料清单，再打开「高级手动列映射与辅助填写」。按同一项目分别选择三张表。序时账选 Excel 行 2–7，余额表和报表选 2–4。逐表匹配表头并确认主体、期间、单位和完整范围。本例的报表映射可直接填入下面的 JSON。恒等式的资产、负债和权益输入框依次填写「资产总计」「负债总计」「权益总计」。核对后点击「运行账表勾稽校验」。团队账表入口当前只查阅已保存快照。 [审易团队账表首版决定](LEDGER_CHECK_ACCESS_DECISION.md)

## 4. 三个失败试验

每次在工作副本或最终文件的另存副本中只做一项改动，记录差异后恢复测试基线。

| 操作 | 应看到的结果 |
| --- | --- |
| 在工作副本把 `原序时账!B2` 临时改成 `SRC-MISSING`。 | K2 出现“未匹配”，暂停出件。恢复 `SRC-01` 后重新核对。 |
| 在值版另存副本把 `序时账!E6` 的 `50` 改成 `51`。 | 借方 `151`，贷方 `150`，差 `1`，与余额表也不一致。恢复 `50` 后重新验算。 |
| 在另一份值版副本新建一张包含 `合成联系人` 的工作表并隐藏。 | 通过取消隐藏或文档检查发现额外工作表。按规则退回重建。提交试跑回执时只使用三个已审查的可见数据表。 |
