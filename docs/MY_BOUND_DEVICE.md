# 我的绑定电脑

在已获准的电脑上完成登录后，展开工作台账号安全区域的“我的绑定电脑”，可查看当前电脑信息和本账号的电脑操作记录。每个账号只看自己的记录，团队管理员和合伙人的身份不会扩大此入口的查看范围。

## 信息说明

| 项目 | 含义 |
|---|---|
| 电脑名称、系统 | 服务端登记的当前绑定电脑，系统显示Windows或macOS |
| 绑定时间 | 服务端记录首次绑定或换机激活的时间 |
| 最近在线核验 | 成功持钥登录、客户端心跳或本次查看等设备认证活动的服务端时间 |
| 电脑记录 | 本账号历代绑定、持钥登录、撤销及换机申请的已保存事件 |

最近在线核验不代表最近一次审计业务操作，也不证明使用者当时在电脑前。早期版本未采集的时间显示“未记录”，不按页面刷新时间或登录到期时间推算；服务端时间仍受服务器时钟影响。

记录每页25项，点击“继续加载记录”查看更早事件，点击“刷新电脑信息”从最新记录重新读取。相同时间的事件使用固定顺序分页，该顺序不说明事件的真实因果先后。

换机申请的名称和系统属于“拟更换电脑”。“申请已批准”表示获得许可，须本人在获批电脑明确激活后才完成换机；“系统记录申请已过期／已失效”的时间是系统确认并保存记录的时间。此处不展示其他审核人的账号或审计资料。

## 连接与换机

断网或设备核验失效时，团队业务暂停并清空此面板的详情；重新连接核验后再展开读取。关闭面板、退出账号或切换账号也会清空已显示记录，旧请求不能回填新账号的界面。未绑定、不同密钥或已撤销的电脑须先完成既有核验流程，不能仅凭密码查看全部电脑历史。

更换电脑沿用[换机审批流程](DEVICE_REPLACEMENT.md)：员工由团队管理员审核，管理员本人由产品负责人审核。该面板用于查看信息；设备登记、申请、批准和激活仍使用原有流程。

## 实现与验收状态

Windows本地候选已完成本轮功能与验收，可按上面的步骤查看本人电脑与记录；这不代表产品已经正式上线。技术范围见[执行合同](MY_BOUND_DEVICE_CONTRACT.md)，分层验证记录见[当前检查点](../进度.md)。

Mac实机、真人系统文件选择器、真实跨电脑、正式短信／微信、签名发行和国内生产部署仍待分别验收。当前使用隔离合成数据，审计业务规则及双方业务签收另行确认；本入口不增加项目或专业模块权限。
