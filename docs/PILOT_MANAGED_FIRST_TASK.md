## 开通团队和两席

1. **产品负责人**使用启动窗口提供的合成账号和密码登录，按提示绑定当前电脑。在「人工审核开通团队」录入合成团队名称和启动窗口所列首管理员手机号。核对提交后的申请行，输入本人密码批准，复制本轮首管理员一次性凭据，然后退出。
2. **首管理员**在登录页打开「首管理员激活」。输入对应手机号及一次性凭据，先核对团队再请求验证码。在启动窗口查看本次请求的新验证码，填写合成姓名并自设本轮密码，完成激活。回到登录页正常登录并绑定电脑，查看「员工邀请」，然后退出。
3. **产品负责人**重新登录，在已激活的申请行填写未来的试点截止时间和 2 个员工席位。首页没有目标申请时，点「下一页」查找较早的记录。按界面标注的北京时间填写截止时间，输入本人密码后批准，在当前页核对期限和席位，再退出。
4. **首管理员**登录后，在「员工邀请」用启动窗口提供的两个员工手机号，分别发送一份助理邀请和一份实习生邀请。在同一轮查看「订阅与席位」，确认邀请预留两席，然后退出。
5. **两位员工**依次从登录页「受邀激活账号」核对各自邀请和岗位，再请求验证码。使用启动窗口对应号码的新验证码，录入不同的合成姓名并各自设密，激活后正常登录和绑定电脑，随后退出。**首管理员**重新登录，刷新订阅页，核对两席已启用。在「员工业务职级」找到刚激活的助理，验证当前密码并确认调整为项目经理，再退出。

如果邀请已创建但列表暂未刷新，先复制本次邀请码，再点「回首页刷新并清除邀请码」。刷新后核对同一条待激活记录和预留席位，再继续下一份邀请。

## 断线后继续开通

- 产品负责人批准首管理员后若未收到回执，恢复连接后在「人工审核开通团队」点「刷新审核记录」。核对原申请状态。待激活的邀请码已遗失时，先确认指定本人尚未激活并撤销原凭据，确认撤销后再录入新申请。已开通的团队继续使用原首管理员账号。
- 首管理员创建员工邀请后若未收到回执，回到原团队点「核对本次邀请」。找到待激活记录且邀请码已遗失时，确认员工尚未激活，再明确撤销核对出来的邀请。确认撤销和席位释放后再发新邀请。暂未查到记录时，可按提示填写原手机号并用原编号重试。
- 刷新「订阅与席位」查看已启用、邀请预留和可用数量。邀请码仍显示时，先交给指定本人，再刷新、关闭面板或退出。评审回执只记录脱敏结果。

## 完成一次指派、提交和核对

1. **项目经理**用原账号登录，在「项目采集与资料核对」新建采集工作区，按演练勾选查阅、管理与核对并验证本人密码。在项目内建一项采集任务，从任务行打开分工，按姓名选择实习生并确认。可另外创建一项任务保持未指派，用于对照实习生列表。完成后退出。
2. **实习生**登录后核对任务列表，只应看到明确指派给自己的任务。打开该任务，点击「选择文件并提交」，在 Windows 文件选择器中选取启动窗口给出的 `managed-pilot-original.txt`。记录已提交状态、文件名及摘要，然后退出。
3. **项目经理**重新登录，在已指派任务行点击「选择资料核对」，使用「软件内预览」核对合成原件正文和摘要。任务保持已提交。采集核对和专业审核分别按各自已批准的流程办理。

## 四席开通和职级调整

1. 双击同一个入口开始新一轮。有尚未关闭的两席演练时，先退出该轮账号并关闭该演练桌面。按「开通团队和两席」的第 1 至 3 步从头操作，批准试点时填 **4 个员工席位**。本轮首管理员只采用技术管理身份。
2. **首管理员**在「员工邀请」给启动窗口显示的实习生号码发实习生邀请，给助理、拟任经理和拟任合伙人的三个号码各发一份助理邀请。逐一记录邀请码与对应号码，核对「订阅与席位」已预留四席。
3. **四名员工**依次从登录页「受邀激活账号」使用各自的号码和邀请码。核对团队和受邀岗位，根据启动窗口中该号码最新的验证码完成激活。各自填写可区分的合成姓名，设密、登录并完成首次绑机后退出。
4. **首管理员**刷新「订阅与席位」，核对四席已启用、邀请预留已归零。在「员工业务职级」通过合成姓名确认两名对象，输入本人密码并分别将拟任经理调整为项目经理、拟任合伙人调整为合伙人。余下两名员工保留实习生和助理职级。确认首管理员可使用员工和席位管理入口，再退出。

## 核对四职级的项目权限

1. **项目经理**登录，在「项目采集与资料核对」新建采集工作区。勾选本人读取、管理和核对三项权限，确认后验证本人密码。在工作区创建两项标题可区分的合成任务，例如「采集银行对账单」和「采集业务凭证」。在各自任务行点击「打开下方任务分工」，第一项只指派给实习生，第二项只指派给助理。可再留一项未指派任务，用于对照。
2. **实习生与助理**依次登录，在「我的采集任务」核对列表，分别搜索另一人的任务标题。每人应只看到自己获指派的任务，查不到对方与未指派任务，也无法打开全项目资料。在自己的任务中依次用「选择文件并提交」选取启动窗口给出的 `managed-pilot-original.txt`，核对「已提交」及本人提交记录。请用任务标题和提交人区分两份记录。
3. **项目经理**重新登录，在两项任务旁点击「选择资料核对」，分别用「软件内预览」查看对应提交，核对提交人、文件名和摘要。关闭预览后查看任务仍为「已提交」。
4. **合伙人**先登录核对项目范围。未获该工作区授权时，项目列表中应找不到它。切回项目经理，在「本项目采集授权」选择合伙人，只勾选「读取本项目采集任务」，确认并输入本人密码保存。合伙人重新登录后应能看到该项目的任务列表，任务行无分工操作和「选择资料核对」入口。
5. **项目经理**在同一项目为该合伙人保留任务读取权，再单独勾选「核对本项目提交资料及原件」。确认并验证本人密码后，合伙人重新登录，从「选择资料核对」预览同一份已提交原件，确认分工操作仍不可用。再由首管理员登录核对，项目授权变化后技术管理身份仍无法访问本项目的任务和原件。

从项目入口查看提交及原件需要该项目的任务读取权和独立资料核对权。此次记录预览结果和权限范围，任务继续显示「已提交」。专业复核、审计结论和报告签发按各自的业务流程处理。

关闭桌面前先退出当前账号。退出并关闭桌面后，本机演练服务随之结束。评审回执可记录角色、观察和本轮目录，省略密码、验证码和一次性凭据。需要再演练时双击入口开始新的一轮。 [双人评审单](PILOT_OWNER_REVIEW.md)
