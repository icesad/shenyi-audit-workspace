# Windows 合成底稿评审

从解压后的评审包启动 `Start-Team-Pilot-Candidate.cmd`。可沿用采集走查窗口，也可重新启动取得一轮干净的演练。使用包内的两个合成文件，Windows 选件窗口打开后，从解压目录进入 `review-inputs`。

| 用途 | 文件 |
| --- | --- |
| 原立项来源 | `synthetic-formal-source.json` |
| 同一来源的完整底稿包 | `synthetic-complete-workpapers.zip` |

## 创建项目并确认来源

1. 用启动窗口列出的 `manager-a` 登录，按提示完成本轮电脑绑定。
2. 打开「项目采集与资料核对」，输入新的工作区名称。保持三项初始采集权限未勾选，勾选创建确认，填写当前密码，再点击「确认创建采集工作区」。刷新项目列表，打开刚创建的工作区。
3. 点击「选择已保存的中标／立项来源」，在 Windows 文件对话框选择上表的 JSON。核对来源标识和项目摘要，逐项确认来源和业务事实，填写当前密码并点击「确认正式立项业务事实并关联来源」。看到负责人业务确认成功后继续。

## 迁入并另存保存版本

1. 打开「项目底稿」，在列表选中新建项目。作为项目负责人选择本人，为本次演练明确勾选查阅、填写和导出，勾选「我已核对人员及三项授权」，填写当前密码，再点击「确认修改底稿权限」。三项权限分别生效。
2. 点击「选择完整底稿包」，在 Windows 文件对话框选择上表的 ZIP。确认摘要中的来源项目标识与上一步相同，并显示一份既有冻结。勾选来源核对及首次迁入两项确认，填写当前密码，点击「确认迁入」。
3. 在「底稿保存版本 1」中打开 `synthetic.xlsx` 的「原表」。A2 应显示「迁入前已保存填写」，C1 的公式单元格保持只读。打开 `existing-frozen.xlsx`，核对冻结底稿处于只读状态。保持版本 1 的内容，继续导出。
4. 回到保存版本 1，勾选导出确认，点击「导出此保存版本」。在 Windows 另存窗口保存到本轮演练目录或自己选定的空目录。看到「所选保存版本已导出完整底稿包」后，记下文件名与字节数。每次另存使用新文件名，留存输入包。

若迁入结果未知，记录演练编号、原操作编号及提示，在「只读查询原操作」中选择「完整包迁入」核对回执。若导出结果未知，核对另存目标及文件是否存在，保留现场和提示交开发核实。同一轮只将这对文件迁入一个工作区。需要从头复验时，关闭本轮窗口再启动，演练记录会分别保留。

产品负责人记录登录、授权与操作反馈；米老师核对原件呈现、已保存填写、冻结只读和专业措辞。填写回执时只记录合成文件的摘要、版本与证据位置。真实底稿使用和正式业务签发需依各自授权进入后续试点。 [双人评审单](PILOT_OWNER_REVIEW.md)
