# 最高审核账号恢复：首版范围决定

日期：2026-11-17。用户已确认：**首版暂不开放这类账号的恢复功能，具体线下处理规则后续再定。** 本决定覆盖本次问题中的密码丢失和更换电脑恢复；不再将该能力列为首版待实现项。

## 当前行为

产品负责人等最高审核身份不能通过普通员工或团队管理员的密码恢复、换机申请获得恢复。现有拒绝行为保留，不新增应急审核人、恢复票、管理入口或特殊重置接口。正常登录、验证当前密码的本人改密和已绑定电脑使用继续适用各自既有规则。

这里的技术范围以现有 `hasProtectedReviewerHistory` 为准：开通团队、账号恢复、成员访问、换机、管理员业务身份、旧项目迁入六类审核授权表。该检查保留历史记录，即使审核授权已撤销也不自动降为普通恢复对象；六种独立授权不等于六个人，也不推定为同一人所有。

员工仍由本团队管理员审核恢复；团队管理员本人仍由获独立授权的产品负责人审核。两者既有短信与密码验证条件保持。密码恢复与设备换机仍是独立流程，不因其中一项成功自动批准另一项。

## 延后处理的范围

最高审核账号的线下身份核验、办理人、凭证、遗失与异议处理、密码和设备分别恢复的执行方式，均待后续明确决定。当前没有获准的生产应急操作，不把开发演示账号、external兼容适配器或直接改库当作已经批准的线下产品流程。

将来重新纳入开发时，先形成有界执行合同，再实现和独立验收；不得自审或通过循环授权补回权限。这次决定只关闭首版开发缺口，不证明该能力已经实现或通过生产验收。
