# 省级报价依据研究记录

整理时间：2026-11-04。用途是追踪证据和缺口，不是现行收费价目表，也不是自动计费配置。面向内地和港澳台的业务适用范围不同，不能自动互相套用。

## 全国性依据

- 国家发展改革委《关于放开部分服务价格意见的通知》发改价格〔2014〕2755号要求各省、自治区、直辖市依程序放开所列会计师事务所审计服务价格，并清理相关地方价格文件。文件本身不是各省具体费率表。各项业务、地区后续文件及现时适用状态仍需逐项核对。来源：https://www.ndrc.gov.cn/xxgk/zcfb/tz/201501/t20150104_963719.html
- 财政部《会计师事务所一体化管理办法》第八条规定业务收费应以项目工时预算和人员级差费率为基础。该要求不等于政府为各省核定统一工时费率。来源：https://www.mof.gov.cn/jrttts/202205/P020220531557195020769.pdf
- 财政部财会〔2023〕25号禁止事务所以或有收费方式提供审计服务，收费不得以审计工作结果或实现特定目的为条件。收费条款应当由业务负责人审查；界面提醒不能取代合规判断。来源：https://app.www.gov.cn/govdata/gov/202311/22/509551/article.html

## 每省规则入库流程

1. 确定业务类型、法规来源、文号、发布机构、原文链接、发布日期、生效/废止情况及适用区域；非官方来源单列待核。
2. 区分市场调节价、历史政府指导价格、采购个例与事务所内部规则。标注资料取得日期和证据局限，不将历史文件、折扣或采购个例转换成所谓“现行官方价格”。
3. 收集可运行的事务所公式和客户脱敏认可算例，验证档位、单位、取值基数、异常、税费、差旅及四舍五入。
4. 规则经事务所负责人确认版本及适用范围后，才进入其正式报价流程。其他地区缺规则时显示未配置，而非复制邻省或显示零元。
5. 配置、审核和报价快照分别版本化；历史报价始终保留当时规则。资料来源记录与当前开发中的内存规则模型尚未自动同步。
