# 报价草稿附件与报价历史调整

日期：2026-11-06。范围：已发布浏览器原型，原 Site 身份与访问范围保持；长期总 GOAL 保持暂停。本次不推进 P02、服务端部署或审计业务后续模块。

## 用户要求及实现

1. 客户报价草稿必须带营业执照和执业证书，各一个真实 PDF / PNG / JPEG 文件，单项上限 3 MiB。无任一附件时预览和登记禁用。
2. 客户页面保留服务、金额和原有初步报价条款，增加项目、发标单位、联系人及两项附件。税率文字明确是百分比，税务口径仍待确认；不加入内部预算、折扣过程或其他地区对比。
3. 完整 ZIP 包固定包含 `报价草稿.html`、`附件/营业执照.*`、`附件/执业证书.*`、`附件清单.json`。清单记录文件大小及 SHA-256，实际文件字节随包导出，而非仅保存文件名。图片可打印；PDF 证照独立附带，不自动打开、不合并入正文 PDF，页面与包内均明确提示。
4. 报价历史业务列为：序号、报价日期、发标单位、项目名称、项目类型、报价金额、是否中标、对方联系人、联系方式。另有操作列，可查看原报价与两项原附件、登记结果及查看更正留痕。待反馈为初始状态，中标/未中标/取消均须人工明确追加。
5. 保存计算草稿不等于已报价。明确点击“登记本次报价”才固定快照和附件引用；默认资质、当前客户或报价参数后续变化不会回改历史。结果追加用当前事件号比较更新，拒绝陈旧标签页覆盖。
6. 历史可检索、按结果筛选，CSV 导出九列且精确到分，防常见公式注入。完整 JSON 归档含原附件、联系人与结果事件，沿用现有下载器的 UTF-8 BOM；当前暂不支持自动导入。

## 数据与安全边界

- `quote-packet.js` 是无网络依赖的本地文件验证、草稿渲染、ZIP 模块。每次预览/导出均防御复制字节并重算摘要，不信任调用者元数据。仅接受有限格式特征与图片尺寸；不验证证照真伪、有效期、执业资格或 PDF 安全性。
- `quote-ledger.js` 单独使用 IndexedDB `hengdu.quote.delivery.v1` 版本 1。附件、登记、默认资质的保存采用事务。历史引用固定至附件种类及内容摘要，改名不改旧引用。容量限制为 500 条报价、100 份去重附件、32 MiB 原始附件字节。
- 原计算草稿 v1/v2 localStorage、修订与备份行为保留。无自动迁移、重置或覆盖旧台账接口；未知结构、损坏内容或存储失败明确报错。
- 无文件上传服务、账号、多所隔离、跨设备同步、服务器权限、审批、电子签章或业务承接能力。数据未加密；共享浏览器同源访问者可见。应使用虚构资料验收，不将实际证照提交到代码仓库或发布包。
- 下载报价包或归档不会发给客户，不代表批准报价、中标核验或立项。清理浏览器数据可能丢失台账，必须自行妥善保管导出资料。
