# 商用安全与授权验收基线 v0.1

状态：设计草案，不表示任何防护已实现或经过测试。实际部署方式、合同、性能与离线要求需业务方确定。

## 资产与威胁

| 资产 | 风险 | 最低原则 |
| --- | --- | --- |
| 客户资料、工作底稿、报告 | 泄露、串所、误删、篡改 | 项目级权限、隔离存储、可恢复备份、操作记录 |
| 计算规则与模板 | 复制、意外篡改、版本混用 | 来源及版本可追溯、只读历史快照、发布审核 |
| 自研引擎 | 客户端代码暴露、接口滥用、私有实例被分析 | 降低下发量、访问授权、必要时编译或混淆；不能承诺不可逆向 |
| 许可签发私钥 | 泄露导致伪造授权 | 私钥不进客户端、安装包、日志或代码仓库；受控签发、轮换及吊销 |
| 更新包 | 被替换、降级、错误版本造成丢数据 | 验证签名、版本兼容检查、备份、受控回滚 |

攻击面分别考虑浏览器、供应商托管服务、事务所私有实例和完全离线交付。事务所掌控服务器或本地计算文件时，可访问的程序、算法和 Excel 公式最终有被分析的风险。软件保护不能破坏客户合法访问、导出与审计留痕。

## 必须通过的测试用例（均为计划）

1. **边界**：测试包、前端资源、源码仓库、日志与安装包中无签发私钥、数据库密码和生产密钥。自动扫描结果存档；人工复核密钥管理流程。
2. **许可签名**：使用测试密钥签发授权；篡改有效期、模块、实例或事务所字段后验证失败；换签名、缺字段、非法格式、错误公钥均明确拒绝。
3. **许可生命周期**：验证到期、续期、撤销、离线宽限和系统时钟异常；不因验证异常删除或破坏数据。合同约定的只读与导出路径可用。离线撤销无法实时生效，需规定同步频率与残余风险。
4. **完整性与恢复**：更新包签名错误、文件损坏、版本不兼容时不执行更新；模拟中断后保留可恢复版本并验证数据一致性。签名验证完整性，不是保密或防逆向保证。
5. **事务所隔离**：两家模拟所互换身份、客户 ID、文件链接、缓存键和任务 ID 均不得跨所访问。备份恢复仅进入授权目标；后台任务必须携带可信上下文。
6. **访问与审计**：无权用户不能查看、导出、改价或发布规则；高风险操作记录谁、何时、对何对象做了什么和结果，但不记录密码与客户明文全文。
7. **文件执行隔离**：上传包含宏、外链与恶意样本的测试文件，不得自动执行宏、联网或向系统目录写入；必要计算在获批的受限环境进行，并测试超时与中断。
8. **逆向暴露评估**：对授权的测试产物检查可直接获得的逻辑、源码映射、密钥及接口权限；记录复现、影响、整改与剩余风险。不以任何单一工具打不开为合格标准。
9. **灾备与退出**：实测备份、恢复、升级回退和客户数据导出。恢复时点、耗时、介质与保留期按试点和合同确定；无法恢复不准生产上线。

## 发布记录

每项记录：测试版本、环境、人员、测试步骤、期望、实际、证据位置、结论及未关闭风险。所有未通过项目在风险获得授权批准前不得标为生产就绪。历史公开价格文件不是本所独占秘密；研发 IP、第三方许可与事务所模板权利须分别梳理。
