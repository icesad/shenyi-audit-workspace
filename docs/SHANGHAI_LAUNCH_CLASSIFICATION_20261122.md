## 2. 备案与增值电信业务经营许可不是一回事

《互联网信息服务管理办法》区分经营性和非经营性互联网信息服务：经营性互联网信息服务实行许可制度，非经营性互联网信息服务实行备案制度。网站应按其实际业务性质办理相应手续；不能把“ICP备案”和“增值电信业务经营许可证”混成一个事项，也不能仅凭“网站收费”或“SaaS”名称判断。是否落入《电信业务分类目录》，须结合实际功能、服务对象、收费方式和交易关系判断。

工信部《电信业务分类目录（2015年版）》包含B21在线数据处理与交易处理、B25信息服务等类别。2025-11-04湖北省通信管理局的许可常见问题进一步列明：企业利用自有网站/APP自营销售自身商品或服务、没有第三方入驻销售，以及自行发布信息且不为其他用户提供信息发布平台服务的情形，无需取得《增值电信业务经营许可证》。这是一项重要的政策解释参考，但运营主体在上海，仍需把本项目实际功能向上海市通信管理局确认，不能把异地问答当作上海个案审批回执。

本项目当前描述更接近“企业自营销售本企业团队审计协作软件；客户在受限团队空间处理自己的资料”，而不是开放式多商户交易平台或公开内容社区。此为咨询事实描述，不是最终许可结论。

### 向上海市通信管理局确认的问题

建议通过上海市通信管理局官方政务渠道提交以下业务描述并保存咨询编号、日期和答复原文：

> 上海灵智涌生科技有限公司拟通过自有官网销售本企业开发的审计团队协作软件，收费项目为团队年度软件订阅及员工席位增购。网站只销售本企业自己的软件服务，不允许其他企业或个人以自身名义入驻销售，不提供第三方商品交易、撮合或结算。客户登录后在企业团队和项目权限范围内处理本企业的审计资料；资料不在公开网站向公众发布，不提供公开论坛、公开文件分享、面向第三方的内容发布平台或公开信息检索服务。官网计划接入微信支付 Native，仅用于收取本企业软件订阅费用。
>
> 请确认：①该模式是否属于企业利用自有网站自营销售、无第三方以自身名义入驻销售的许可豁免情形；②官网自行发布本企业产品信息、帮助文档是否属于自行发布而非为其他用户提供信息发布平台；③受限团队内的资料存储、处理、协作功能是否另涉及B25或B21；④官网与团队API分别应办理何种许可或备案、是否需按两个子域名分别填报；⑤未来增加第三方商户入驻、公开内容发布或交易撮合，是否会改变许可判断。

上海市通信管理局2024年公告鼓励企业自行通过工信部政务服务平台提交经营许可申请，并通过接入服务提供者提交ICP备案；公告明确不指定中介，也不向申请人收取许可/备案申请费用。

## 3. 上海企业许可/备案材料准备

先由主管部门确认业务性质，再按经营性许可或非经营性备案的对应流程提交。以下是接入服务商/管局要求的预备资料，不预设本项目一定只走非经营性ICP备案。

按阿里云当前《上海备案规则》预先准备，最终以接入服务商备案系统和管局审核为准：

- 企业主体证件：营业执照原件拍照件；公司全称、住所和统一社会信用代码与备案主体一致。
- 主体负责人：按上海规则填写单位法定代表人；阿里云2026-09-14更新的上海规则列明主体负责人须年满16周岁，16至未满18周岁需提供有效工作证明。
- 网站负责人：须年满18周岁并完成平台要求的人脸核验；若不是法定代表人，准备法定代表人签署的上海专用授权委托书。上海授权书需使用对应的专用模板，并按备案系统要求填写网站/APP信息。
- 域名：完成实名认证，域名有效期超过30天，确认注册商和域名后缀支持备案。阿里云说明实名/过户后预留约3天让信息同步管局。
- 网站信息：网站名称、服务内容、负责人和域名与实际官网一致，不使用占位域名或虚构业务描述。
- 云资源：如解析到中国内地服务器并对外提供Web服务，需先有符合备案要求的内地接入资源。购买前核实产品类型、地域、购买时长及备案服务码/可备案网站数。
- 账号：确认企业是否已有ICP备案主体及原备案账号。阿里云说明一个账号只能备案一个主体；已有备案时按实际情况办理变更或新增接入。

不要先买一台“看起来便宜”的ECS再补备案资格。先在备案控制台核实实例是否支持备案、购买期限和备案服务码数量。

## 4. 域名与入口规划

仓库中的 `www.shenyi.example` 和 `team.shenyi.example` 都是保留示例域名，不能解析到公网或提交备案。

建议在一个企业持有、完成实名认证的正式主域名下规划：
- `www.<正式域名>`：公开产品官网。
- `team.<正式域名>`：受限团队服务/API。
- 暂不增加不必要的第三个入口；如后续增加 `docs`，先确认备案记录要求。

待查询可用性、商标近似和备案资格的域名候选（均未确认可注册）：
- `shenyiaudit.cn`
- `shenyi-audit.cn`
- `shenyiaudit.com`

注册前核对域名是否可注册、注册人能否登记为运营企业、注册商是否支持备案、首年与续费价格、DNS管理和证书自动续期。只有选定并核验后再购买；本阶段不自动注册或支付。

## 5. 云部署和官网发布准备

仓库已有静态官网构建和Nginx候选：
- 构建：Node.js 24.15以上的24.x，在仓库根目录执行 `node scripts/website-preview.mjs --build <仓库外的新目录>`。
- 静态白名单：`index.html`、`styles.css`、`assets/brand-shenyi.png`。
- 官网Nginx模板：`deploy/linux/nginx-shenyi-website.conf`，当前严格只开放首页、CSS和品牌图片；需统一替换示例域名、证书路径和TLS设置。
- 团队API模板：`deploy/linux/nginx-shenyi-team.conf`，当前仅把指定API反代到本机回环后端。
- 数据库、证书私钥和生产配置放在发布目录之外；生产验收还需真实域名TLS、DNS、防火墙/安全组、备份恢复、监控告警、版本签名、回滚责任人和办公网络访问。

现有Ubuntu/Nginx结果是隔离合成环境验收，不代表已购买国内云主机或已部署公网生产站点。GitHub合并也不会自动发布网站。

## 6. 微信支付首发准备

现有产品文档已选择微信支付 Native 扫码作为首发通道，但真实商户开通状态未知。企业侧需核对营业执照、法定代表人核验、对公账户、商户号、Native产品权限、适用且已认证的AppID及商户绑定。随后在真实商户测试环境验收下单、扫码、回调验签、主动查单、账单对账、退款和权益到账。合成密钥、合成商户号和回环HTTPS结果不能替代真实商户验收。

## 7. 采购和上线顺序

1. 核验营业执照主体信息、经营范围及企业是否已有ICP备案。
2. 向上海市通信管理局确认本项目许可分类，保存可追溯答复。
3. 确认品牌域名、注册主体和备案资格，再注册并实名认证。
4. 确认阿里云账号、内地地域、合格备案产品、购买期限和备案服务码后再采购。
5. 通过接入商提交ICP备案并完成管局核验。
6. 部署静态官网和受限团队API，完成真实域名TLS、权限、备份恢复、监控、回滚和安全验收。
7. 完成微信真实商户开通与支付闭环，再按企业批准的价格、合同、发票、退款和隐私条款开放收费。
