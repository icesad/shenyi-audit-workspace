# 米老师的审易试用说明

**先看业务，请下载 A 包。要试员工登录、权限、续费或加席，再下载 B 包。** 所有练习用虚构资料。在另一台电脑上可以独立完成，不需要 Git、开发环境或正式账号。

## 下载安装包旁边的测试资料

1. 用米老师自己的 GitHub 账号 `mixue117` 登录，打开[仓库 Releases](https://github.com/icesad/shenyi-audit-workspace/releases)。
2. 找到带 **Draft** 标记的「审易双人试用｜业务工作台、团队权限与模拟续费」，展开 **Assets**。A 包叫 `A-Shenyi-Business-Review.zip`，B 包叫 `B-Shenyi-Team-Review-0.73.2-Win-x64.zip`。草稿只对有相应权限的协作者可见。
3. 右键 ZIP，选「全部解压」。两包各解压到一个新文件夹。以下操作都在解压后进行。

## A 包 · 先看米老师的六个业务模块

用电脑上的 Edge 或 Chrome 打开 **`dist/index.html`**。要看官网外观，再打开 **`website/index.html`**，点击「版本与下载」。A 包只有网页，无需安装，Mac 也可用浏览器尝试。本次实测环境为 Windows Edge。

| 从左侧点哪里 | 可以怎样试 |
| --- | --- |
| 招投标及记录 | 在报价页填一条虚构项目，检查金额、计算口径和报价文字。 |
| 项目汇总表 | 查看登记字段。空列表时，先回招投标按原流程登记一笔虚构中标项目，再看能否找到同一项目。 |
| 审计程序 | 依次点「资料收集与核对」「账表校验」「底稿目录」，查看步骤、缺资料提示及对应原件。 |
| 报告出具 | 打开「试算平衡表9200」「审计报告」「审计底稿归档」，核对来源和缺件提示。 |
| 成本核算 | 在「项目成本核算」查找同一项目，检查人工费、差旅费的输入与显示。 |
| 资料库 | 打开「投标方信息库」「审计底稿模板」「收费依据」，确认能找到常用内容。 |

建议从「虚构测试项目一」走一遍报价、中标、立项和成本。需要先建项目或补资料的步骤，以页面提示为准。A 包按本机浏览器保存数据，复测请使用同一浏览器和解压位置。两台电脑各有自己的记录。

## B 包 · 用不同身份测试团队和订单

需要 **Windows 10/11 x64**。建议解压到短路径，例如 `D:\ShenyiTest`。先双击 **`Verify-Owner-Review.cmd`**，看到「评审包校验通过」再继续。每次只打开一个入口，保留随之打开的命令窗口。使用包内合成账号及样例；遇到杀毒软件告警时停止操作，记下文件名和提示。

| 想试什么 | 双击哪个文件 | 怎样判断 |
| --- | --- | --- |
| 实习生、助理、经理、合伙人的区别 | `Start-Team-Pilot-Candidate.cmd` | 先用 `intern-a` 查看本人任务，再退出，在同一窗口用 `manager-a` 核对项目资料。四种角色及测试密码在 `docs/TEAM_PILOT_REHEARSAL.md`。 |
| 团队首次开通、邀请和设备绑定 | `Start-Team-Managed-Pilot-Candidate.cmd` | 按启动窗口显示的本轮账号登录，完成本机首次绑定。需要走完团队审批时参看 `docs/PILOT_MANAGED_FIRST_TASK.md`。 |
| 官网创建续费单、增购席位单 | `Start-Team-Website-Checkout-Candidate.cmd` | 用窗口提供的合成技术管理员登录，从「订阅与席位」打开官网。选席位、核对报价、建单后，回桌面核对订单号。 |
| 模拟收款、续费到账、退款受理 | `Start-Team-Billing-Candidate.cmd` | 使用 `billing-admin-demo`，按 `docs/M5_LOCAL_ACCEPTANCE.md` 核对预置年费单或增购单，查看到期日和席位的变化。 |

官网下单和模拟到账是两次独立练习，各有自己的订单。切换角色请点「退出账号」，在同一轮内重新登录。关闭应用后服务结束，再次启动会创建新的练习环境。

## 哪些结果需要另外验收

这里可以体验官网页面、六模块业务、团队权限和模拟订单。官网的公网下载、正式安装器安全提示、客户端在线更新、微信真实收款，以及两台电脑连接同一服务互看资料，仍需各自的正式环境和测试记录。体验时无需付款或点击安全软件的「信任」。

## 发现问题怎么记

请写下 **A/B 包 → 入口或账号角色 → 点了什么 → 预期 → 实际看到什么**，附一张只含虚构资料的截图。例如「B 包，经理，在采集核对中打开刚提交的原件，预期看到附件，实际提示无权限」。业务计算有疑问时，请附上输入金额和你预期的结果。
