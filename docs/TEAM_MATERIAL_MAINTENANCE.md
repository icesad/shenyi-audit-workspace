# 团队资料原件维护

本功能使用独立“维护原件”权限，覆盖新增原件和移除当前关联。项目负责人输入当前密码，明确授予自己或本项目合格经理／合伙人；同时必须具有资料查阅权。首次导入、核对、关门／重开及负责人身份本身不附送维护权。

## 正常操作

1. 登录完成本机设备核验，在项目资料面板选择获授权项目。首次开通及旧资料导入仍按[资料模块说明](TEAM_MATERIALS_MODULE.md)办理；当前只使用合成数据验证，不自动搬客户资料。
2. 负责人查找授权对象，勾选“查阅”和“维护原件”，核对其他权限，输入自己当前密码并确认保存。核对、关门权限仍分别选择。
3. 在当前层级清单选择具体叶标题，再选择一份原件。预检显示目标、最终保存文件名、类型、大小及SHA；原入库规则可能整理文件名，以预检显示的最终名为准。
4. 核对新增影响并明确确认。新增会按原规则把该叶变为“已收到、未核对”，旧的核对通过／不适用结论需要有核对权者重新处理；本操作不自动核对。
5. 要移除时，选择当前附件的“移除关联”，填写理由并明确确认。只移除当前关联，旧原件及历史全部保留；还有附件时为“已收到、未核对”，最后一份移除后为“待提供”。
6. 在全部历史中，依当前查阅权继续使用[软件内预览](TEAM_MATERIAL_PREVIEW.md)或“保存原件”。没有维护权也可按原查阅权阅读；没有查阅权不会下发完整清单和历史。

同名文件也会形成新的原件，不覆盖旧UUID或字节。已经关门的清单必须先由独立有重开权者说明理由并重新开门；维护权本身不能重开。项目冻结或归档、旧版逐行schema1无标题附件、叶标题已满10份时均不能直接新增；软件不自动升级旧记录或替换标题树。

## 取消、结果未知与限制

- 未发布的本次来源可取消，换项目／账号／设备、关闭面板、过期或失权后须重新选择。预检来源最多保留10分钟，原件不暂存为公共磁盘文件。
- 发送前就显示查询编号。遇到“结果未知”，恢复设备连接后只读查询原编号回执，再刷新当前资料；不要重复提交相同新增／移除。已发出的提交不能靠关闭窗口撤回。
- 单份1字节至12 MiB，每叶当前最多10份；全部历史原件累计150 MiB，移除不会释放历史额度。原有正文、宏／XML、事件和记录大小限制继续有效，不以扩展名或SHA代替正文检查。
- 撤权后停止后续读取及发布，清理可控的本机来源和旧显示；已合法保存的副本不能远程收回。维护及查阅仍不代表审计签发资格。
