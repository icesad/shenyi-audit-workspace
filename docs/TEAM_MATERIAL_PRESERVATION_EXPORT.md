# 团队资料完整保全导出

本功能把当前资料清单及**全部历史引用原件**保存成一个ZIP，包括已移除关联的原件和旧导入代次。需要当前项目明确授予的资料查阅权；经理、合伙人或项目负责人身份本身不会自动开通。冻结项目和已关门资料仍可按查阅权导出；归档项目不能导出。

## 在团队客户端保存

1. 正常登录并连接已绑定电脑，进入获授权项目的资料清单。
2. 阅读完整历史范围提示，勾选确认，再点击完整保全导出。
3. 选择保存位置。取消此对话框不会生成或下载整包。
4. 等待完成，以界面返回的文件名、大小、SHA-256和原件数量核对保存文件。

处理期间可点击取消。切换账号、项目或断开设备连接会停止尚未发布的导出；读取权、资料或项目版本改变时，整个导出拒绝继续，不省略原件。发布开始后的取消不代表撤回文件；如果提示已发布或结果需核对，请先查看原保存位置，避免重复操作。

每个原件最多12MiB、原件合计150MiB、最多5000件，整包最多180MiB。超出既有上限时拒绝整包，不截断。资料区必须已有合法清单；没有清单时不能导出一个看似成功的空备份。已有清单但原件为零的情况允许导出。

## 在原本机版本恢复

1. 另留原始v2 ZIP。恢复时团队来源只用于本次提示，随后本机再次导出的包不保留这份来源声明。
2. 在原本机版本选择已存在、业务UUID相同的正式项目，确认它的资料区为空。团队资源UUID和原业务UUID可能不同，以预检显示的原业务UUID为准。
3. 点击资料保全包恢复，选择ZIP。核对项目、正式范围、完整历史数量、SHA-256和团队来源提示。
4. 勾选明确确认并确认恢复。已有清单、孤立原件或全局原件UUID冲突时拒绝写入；不会覆盖、合并或自动改号。
5. 恢复后重新打开资料区，核对清单、关门状态、历史及原件下载。列表刷新失败时应按提示先核对实际结果，不重复恢复。

恢复保留原记录、历史、UUID和原件字节，不继承团队权限或当前员工身份。当前团队迁入接口仍只接受原v1格式，不能直接把v2保全包作为团队迁入授权。

## 包的证明范围

v2包记录团队资源与原业务身份、项目/资料版本及文件摘要。它提供内容一致性检查，来源声明没有服务器签章，不是现实中标核验、当前员工签审、审计报告签发或团队归属证明。即使所有摘要都一致，也不能独立认证来源。

包不包含其他专业模块、立项报价来源、合同、成本、员工账号、授权配置或整个数据库。请把它作为本资料区的历史保全文件保存，按团队原有资料保管规则管理已合法导出的副本。
