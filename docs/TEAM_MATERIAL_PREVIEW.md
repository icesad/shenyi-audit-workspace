# 团队资料原件只读预览

从团队资料清单或全部历史记录，可以把获准读取的原件打开为独立阅读窗口。它沿用材料查阅权限，不附送项目、核对、关门或签发权限。预览不修改原件，也不把资料标记为已核对。

## 使用路径

1. 登录并完成本机设备核验，在“项目采集与资料核对”选中获授权项目，展开“资料清单、历史与原件”。项目须已按 [归属登记](LEGACY_PROJECT_REGISTRATION.md) 和 [资料模块说明](TEAM_MATERIALS_MODULE.md) 完成相应授权及首次导入。
2. 在当前资料项或“全部资料操作历史”中点击“软件内预览：文件名”。已移除或旧代原件仍依当前材料查阅权检查，不根据历史姓名放行。
3. 软件核对来源、版本和真实字节后，在独立窗口显示正文、表格、图片或分页。检查窗口里的实际读取提示；窗口出现不等于格式已完整解析。
4. 使用窗口内“关闭预览”、Esc 或系统关闭按钮退出。保存原件请回到工作台点击“保存原件：文件名”，继续使用当前权限复核和系统保存流程。

预览窗口不提供下载链接、编辑、外链、公式计算或宏执行。HTML/XML/Markdown 标签按原样文本显示；SVG会清除脚本、外链及不允许的元素。它不打开外部应用，也不向文档里的网址发送请求。

## 格式及精度

| 类型 | 阅读方式和边界 |
|---|---|
| PDF | 本机逐页画布、翻页；不执行表单动作或JavaScript，不进行OCR |
| DOCX／PPTX／ODT／ODP | 原读取器的正文、可识别表格与图片；Word结构分页不是原打印分页，复杂版式应核对原件 |
| XLSX／XLS／ODS／CSV／TSV | 工作表、合并区域及缓存单元格值分页只读；不重算公式、不联网更新外链 |
| DOC／PPT／RTF | 沿用旧读取器安全文字提取；可能无法还原原分页、图片、嵌入对象和复杂版式 |
| 图片／SVG | 本机解码／净化后显示；超大尺寸会停止，不以已上传推断一定能预览 |
| TXT／JSON／HTML／XML／Markdown | 有界惰性文字；标签和脚本不执行 |
| ZIP | 只读目录，不执行或自动展开其中原件 |
| RAR或不兼容内容 | 本片不放宽动态执行策略；若无法安全读取，会明确提示回工作台按权限保存原件 |

单份沿用12 MiB上限，另保留原读取器的展开大小、文字、节点、图片及解析时限。损坏、加密、超限或无法解码时不裁剪成“完整成功”，原字节不改动。以上是阅读方式说明，具体格式和平台通过证据以本轮实际验收记录为准，不代表Office应用或Mac实机验收。

## 权限与窗口生命周期

服务端在首次读取及显示前重新检查查阅权、项目／材料版本、原件长度和SHA。账号或设备暂停、换账号、工作台重载／退出、材料面板关闭后终止本次窗口；显示期间每5秒进行非重叠核权，服务端拒绝后续读取，窗口在核权失败或版本变化时关闭。已显示的像素或已合法保存的副本无法远程收回。

冻结项目和旧已关门清单按已有查阅权可读，归档项目拒绝。正常重新登录或重新获得权限后，需要主动重新打开原件，不自动恢复旧窗口。
