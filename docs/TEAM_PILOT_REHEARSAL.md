# 审易团队采集合成演练

产品负责人和米老师可以在同一个独立候选窗口演练四个角色。产品负责人操作账号、任务范围和权限变化，米老师核对原件呈现、提交状态和退回用语。先走只读路线，记录结果后再选做改派或退回。两人若分别启动候选，各自看到的是一份新环境，操作结果互不相通。可用同一张回执记录采集、账务和官网的走查结果。 [双人评审单](PILOT_OWNER_REVIEW.md)

## 启动和账号

Windows 评审包完整解压后，双击根目录的 [Start-Team-Pilot-Candidate.cmd](../Start-Team-Pilot-Candidate.cmd)。从仓库源码启动时，先按 `desktop/README.md` 准备 Electron，再用 Node.js 24.15 以上的 24.x 在仓库根目录运行以下命令。

```sh
node scripts/team-isolated-preview.mjs --pilot-demo
```

打开的窗口标题为「审易 · 独立合成候选预览 · 编号」。启动终端会显示本轮资料目录、`pilot-demo-cases.json` 和 `pilot-follow-up.txt` 的路径。

所有下列合成账号的密码均为 `ShenyiDemo!2026`。首次登录时核对账号和当前电脑名称，勾选绑定确认，重新输入密码，点击「确认绑定此电脑并进入」。切换角色时点击「退出账号」，在同一窗口登录下一角色。

| 账号 | 初始可验范围 |
| --- | --- |
| `intern-a`（实习生） | 本人任务「收集银行对账单」和「银行对账说明（已提交示例）」。已提交示例有一条原件记录「合成银行对账说明.txt」。 |
| `assistant-a`（助理） | 独立任务「收集业务凭证」。实习生的任务和原件不在其任务范围。 |
| `manager-a`（项目经理） | 「合成项目A」负责人，具备该项目采集任务读取、管理和提交资料核对权限。可调整该项目其他经理或合伙人的采集授权。 |
| `partner-a`（合伙人） | 在「合成项目A」可以读取采集任务、打开任务分工，初始没有提交资料核对权。 |

## 先看采集和原件

1. **产品负责人用 `intern-a` 登录。** 在「我的采集任务」打开「银行对账说明（已提交示例）」。应显示「已提交」，并提示「本任务已提交，等待负责人核对。」提交按钮禁用。「我的提交记录」只有一条「合成银行对账说明.txt」。点「软件内预览」，应能读到「本文件用于练习采集和核对，全部数据为演练内容。」请米老师核对可读性，再关闭。另一个本人任务「收集银行对账单」应为待提交。
2. **产品负责人切换到 `assistant-a`。** 应能打开「收集业务凭证」。在任务中查找「银行对账说明（已提交示例）」应无匹配。两个低权限账号均无项目采集授权、全项目提交核对和其他项目资料的入口。
3. **米老师用 `manager-a` 登录。** 打开「项目采集与资料核对」，选「合成项目A」，在示例任务旁点击「选择资料核对」。应看到一条提交，提交人为 `intern-a`，原件名、大小和 SHA-256 与实习生所见一致。点击「软件内预览」，核对能否直接读到内容、关闭后能否回到当前任务。此步仅查看，不点击保存副本或分工。预览不会改变提交状态，不形成审计结论或签发。
4. **米老师切换到 `partner-a`。** 进入同一项目，应能看到示例任务和「打开下方任务分工」。任务列表的提示只引导处理分工。该任务旁没有「选择资料核对」，无法从项目入口读取提交列表或原件。记录这一差异，再决定是否演练授权变化。

## 选做授权、退回和改派

以下操作会改变当前合成环境。先保存上面的只读记录。需要从头复验时，关闭本候选后重新启动。

1. **按项授权和撤权。** 用 `manager-a` 打开「合成项目A」的「本项目采集授权」，选择 `partner-a`，保留读取和管理，仅新增「核对本项目提交资料及原件」。勾选确认，验证当前密码，点击「确认保存本项目授权」。用 `partner-a` 重新登录，应可通过「选择资料核对」预览同一条原件。再用经理账号取消该项核对权，仍保留读取和管理。合伙人重新登录后应仍能查看任务和打开分工，提交核对入口应消失。授权变化会撤销该对象的旧登录，核对新权限时用新登录。
2. **退回与补交。** 用 `manager-a` 在示例任务旁点「打开下方任务分工」，点击「退回补充资料」。切回 `intern-a`，打开同一任务，应显示「已退回」，原提交仍可查阅，按钮重新允许提交。如需继续，用「选择文件并提交」上传本轮候选目录中的 `pilot-follow-up.txt`。应回到「已提交」，旧原件仍在历史中，并增加一条补交记录。
3. **改派。** 用 `manager-a` 打开「收集银行对账单」的「任务分工与退回」，查找并选择本团队 `assistant-a`，点击「确认改派并替换当前分工」。分别重新登录，核对实习生列表不再有该任务，助理在原有任务之外可打开新分配的任务。改派替换本任务当前分工；旧原件不自动开放给新成员。若要验证带原件的改派，可在另一轮先记录示例原件，再用同样的分工步骤操作该示例。
