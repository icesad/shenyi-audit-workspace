# 受信HTTPS团队服务配置

本片给现有桌面客户端增加固定HTTPS服务配置及预期数据库身份校验。客户端仍执行原有账号、单机绑定、在线核验和团队/项目/任务授权。它是商业化集成候选；当前服务身份和业务数据仍为合成预览，尚未部署国内生产服务。

## 部署配置

由有权管理部署的人将下列JSON保存为客户端本机的独立文件，例如 `D:/Shenyi/config/team-service.json`。不能从不可信邮件、页面或二维码自动接受配置。地址、证书和UUID须与实际部署核对；示例地址不提供服务。

```json
{"schemaVersion":1,"apiBase":"https://team.example.invalid","serverId":"11111111-1111-4111-8111-111111111111"}
```

版本 1 只允许这三个字段。`apiBase` 为规范 HTTPS origin，可以有一个末尾斜线，拒绝账号密码、路径前缀、查询参数或片段。`serverId` 是目标数据库已存在的小写 UUIDv4。配置文件最大 16 KiB，要求严格 UTF-8 和不重复的字段。密码、令牌、证书私钥、代理和跳过 TLS 核验的选项不在配置内。变更部署时先停止客户端，由管理员核对配置并重启。主进程只读取一次并冻结配置。

同时配微信扫码及官网订单时，采用版本 4 并填写 `wechatAppId` 与 `checkoutOrigin`。团队 API 和官网须为不同的标准端口 HTTPS 域名。扫码回调仍在团队 API，年费和增购页面由客户端打开指定官网。实际能力由受信服务启用。 [版本 4 的字段与示例](TRUSTED_TEAM_HTTPS_CONTRACT.md#同时启用微信与官网订单的版本-4-配置)

通过 `SHENYI_TEAM_SERVICE_CONFIG` 指向本机绝对路径，拒绝网络共享和设备命名空间。开发版实际桌面入口的启动示例：

```powershell
$env:SHENYI_TEAM_SERVICE_CONFIG = 'D:/Shenyi/config/team-service.json'
Remove-Item Env:SHENYI_TEAM_API -ErrorAction SilentlyContinue
& 'D:/shenyi-audit-workspace/desktop/node_modules/electron/dist/electron.exe' 'D:/shenyi-audit-workspace/desktop'
```

此命令需要预先具备实际可达的HTTPS服务及正确配置，不会自动部署服务器。通常无需设置旧 `SHENYI_TEAM_API`；若设置，必须与配置的规范origin完全一致。未配置且未打包时保留原本机预览。打包版缺失或无效配置会在创建业务profile、设备vault、窗口或发送请求前退出，不回退到其他服务。

原 `Start-Team-Preview.cmd` 和 `Start-Team-Review-Preview.cmd` 用于启动本机合成服务和桌面，继续采用原loopback地址。不要用这两个本机入口连接远程服务；继承了相冲突的远程配置时客户端会拒绝启动，先在该终端移除 `SHENYI_TEAM_SERVICE_CONFIG` 再启动本机入口。

## 连接校验及用户可见状态

远程请求沿用Node默认TLS证书与主机名验证，拒绝重定向。每次发送密码、验证码、令牌、设备证明或资料之前，客户端先向同一origin发送无秘密的 `/api/auth/methods` 请求，核对服务身份头和严格设备协议；不匹配则不发送后续秘密。实际响应也须来自固定URL并带正确UUID。身份错误使当前会话失效；网络中断按既有规则暂停业务，联网后重新核验。已经发出的写操作仍须查回执核对，不自动重放。

“发送前被拒绝”与“发出后无法确认”须分别处理。已有请求编号的工作区创建、正式立项和资料维护等操作，如果发出后服务身份异常，仍按原编号保留待核对结果；不能据错误提示断定没有写入。退出账号过程中收到旧请求的迟到结果，也不能退出后来登录的新账号。

界面显示配置的HTTPS origin和合成预览说明。UUID、配置文件路径、令牌和设备私钥不下发界面，renderer继续没有通用网络接口。公开origin只用于显示，不是授权来源。新旧账号切换时，迟到的旧响应不能清退新账号或恢复旧授权。

服务端在strict-device模式为统一应用响应添加 `X-Shenyi-Server-Id`，从现有metadata只读取得UUID；缺失或损坏时返回固定503，HEAD始终没有正文。现有开发服务仍只监听loopback且保留Host检查，可由同机受信TLS网关终止HTTPS并转发到私有后端。网关须保留method、path/query、body、Origin和认证/设备头，将上游Host设置为真实后端authority；不放开公网HTTP或接受外部伪造身份头。

TLS校验origin；UUID用于防止误连另一数据库，不能替代证书、业务权限或服务器安全。首次配置须由部署负责人验证，不能把从任意URL读到的UUID直接当成信任依据。生产不增加CA覆盖或证书验证旁路；自建测试CA仅用于自有测试子进程，不安装系统根证书。
