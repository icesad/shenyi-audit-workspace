# 第7版：表单统一与预览诊断

## 用户反馈及范围
Mac Safari截图显示文本框与下拉框高度不一致，且预览按钮灰色时看不出具体原因。本轮仅修这些交互问题，不推进其余业务改造或长期暂停GOAL。

## 改动
- 单行文本/数字/日期/search框与select采用一致box-sizing、height、font、padding、appearance。桌面40px/13px字体；≤600px为44px/16px字体并单列，避免手机控件聚焦放大。
- checkbox/radio/file/hidden不纳入统一单行样式；textarea保留多行；新增CSS限定screen，原打印规则不变。
- 按钮旁明确显示客户或金额无效、历史复算待确认、客户元数据未同步、缺少营业执照/执业证书、文件正在校验、登记字段无效、组件未加载或操作中等状态。
- 缺少必填登记字段时从“点击后报错”改为“事先禁用并解释”；更改字段会实时更新状态。客户A→B→A仍必须明确同步，附件读取中不能退回旧附件生成。
- “前往补齐报价信息与附件”只滚动定位，不自动清空客户资料；原同步按钮仍须明确确认。

黄色离线提示和低于工时预算提示不是直接禁用预览的条件；不自动为客户填造资质文件。

## 本轮验收
- 全套Node/JSDOM及真实IndexedDB模块：154/154，0失败、0跳过。
- 原生Chromium整站：14/14步骤，含原13步及控件尺寸和诊断显示；桌面所有目标单行控件实测40px，390px视口实测44px，无整页横向溢出；旧报价及两证附件版本不变。
- 测试来源与既有依赖前后摘要一致，0页面错误；自有资源正常关闭。ROOT实际查看桌面/手机截图。
- 未进行原生Mac Safari实机测试，需米老师更新离线文件后复测；未声称解决Cloudflare托管平台拦截。

## 版本与数据边界
生成新离线体验包，旧文件不会因在线版本更新自动升级。替换前保留旧包并导出计算草稿备份/台账CSV及附件归档；不同file来源浏览器可能不共享数据，JSON附件台账仍不支持自动导入。不要删除原文件或清理浏览器数据。

本轮不实现报价函新模板、印章/签名上传、额外10附件、移除工时模块、新省份计费规则。仅虚构数据验收，无真实证照/签名/客户原件打包。
